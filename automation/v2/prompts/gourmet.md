
# 業種: グルメ — 特集記事(1 店 1 ページの記事)を書く
店ごとに「導入 → POINT(3〜5)→ 編集部のひとこと → 最後に」の記事を書きます。見本(事実だけで書かれた既存の記事)は `{{WORK}}/example.json` にあります。**型と語り口の見本であって、内容を真似してはいけません**(店の事実は店のものだけ)。

## 量と構成
- lede(導入): 300〜450 字ほど。最初に街の空気や立地(最寄り駅・エリア)、次にその街の中でのこの店の役割。**事実が足りなければ短くてよい。** 「今回は〜5 つのポイントで紹介する」で終えない。
- ranking(POINT): **3〜5 個**。1 個 400 字前後を目安にするが、事実が足りなければ短く、足りなければ個数を減らす(3 個に満たないなら失敗の出口)。
  POINT の役割の目安: 1=店の核になる料理・商品・技術 / 2=他店との違い・通う理由 / 3=素材・メニュー・ドリンクなど具体の魅力 / 4=店内・席・雰囲気・誰と行きやすいか / 5=アクセス・使い方。事実が無い役割は飛ばしてよい。
  各 POINT の `name`(見出し)は具体的に(料金・人気・おすすめは入れない)。`cuisine` は小さな分類ラベル(例「アクセス・営業情報」)。`area` は「市区町村+町名」。`specs` は事実の表 2 つ(`{"k":"営業時間","v":"..."}`。料金の行は作らない)。
- quote(編集部のひとこと): 事実を 2〜3 文でまとめる。評価・感想は書かない。
- closing(最後に): その店に行くときの実用の事実(時間・予約・アクセス・休み)で終える。「編集部が考える」で書き出さない。「初めてなら、まずは」を使わない。
- title / titleHTML: 地域名と店名と店の特徴が入る。titleHTML は title に `<br>` と `<em>…</em>` を足した形(見本のとおり)。「人気」「おすすめ」は入れない。
- subtitle: 「業態 / 都道府県市区町村 / 店の特徴」の 3 つを " / " でつなぐ。
- kicker: 店名の英字表記(公式サイトか Google マップに英字表記があればそれ。無ければ店名のローマ字)+ 地名(大文字)。

## 写真の割り当て(photoPlan)
- `photoPlan.hero`: 記事の主役の写真 1 枚(外観・店内・看板の料理のうち、いちばんその店らしい 1 枚)。使える写真が 1 枚も無ければ null。
- `photoPlan.points`: `ranking` と同じ長さの配列。各 POINT の内容に合う写真の ID(1 枚)。合う写真が無い POINT は null(空の枠のまま)。同じ写真を 2 回使わない。hero と同じ写真も使わない。
- `photos` には、cand/manifest.json にある **全部の候補** について、use / what / kind / reason を書く。

## 出力ファイル `{{OUT}}` の形(これ以外のキーは足さない)
```json
{
  "status": "ok",
  "article": {
    "kicker": "...",
    "title": "...",
    "titleHTML": "...",
    "subtitle": "...",
    "lede": "...",
    "ranking": [
      { "name": "...", "cuisine": "...", "area": "...", "desc": "...", "specs": [ { "k": "...", "v": "..." } ] }
    ],
    "quote": "...",
    "closing": "..."
  },
  "photoPlan": { "hero": "g01", "points": ["g03", null, "s02"] },
  "photos": [ { "id": "g01", "use": true, "what": "...", "kind": "exterior", "reason": "" } ],
  "facts": [ { "claim": "...", "source": "https://... か maps", "quote": "..." } ],
  "sources": [ { "label": "公式サイト", "url": "https://..." } ],
  "notes": "判断に迷った点があれば 1〜2 文(任意)"
}
```
`sources` には、実際に事実を取った公式サイトのページ(label は「公式サイト」「公式サイト(メニュー)」など)を入れる。Google マップは機械が足すので入れなくてよい。
