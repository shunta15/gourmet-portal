# マチノワ グルメ 500店計画（2026-10-01 開始）

ユーザー指示（2026-10-01）:「記事の制作をどんどんしていきたい。グルメの方。500店舗ぐらいにしたい。
街の紹介から店舗の紹介、前から言ってる利用シーンに合わせた紹介をしていきたい」

## 現状（2026-10-01 実測）
- 店舗ページ: 286店（lib/data.ts 228 + lib/teleapo-restaurants.ts 58）。ただし Supabase には 228 しか無く、サイト一覧は228表示（58店が一覧から漏れている）
- テレアポ特集記事（/feature/<店名>）: 319本。うち店舗ページがあるのは店名一致で9本のみ → **約310店が記事だけ**
- 記事 specs の充足: 営業時間 35% / 住所 24% / 最寄り駅 20% / 定休日 20% / 席 49% / 予算 42% / 推奨シーン 8%
- 地域: 16 region に入らない店が約36%（三重55・沖縄35・山口31・石川25 など）
- シーン: 12種（lib/scenes.ts、matchTags でタグ一致）

## 方針
新規の店探しはしない（実在・掲載合意済みの「詰めOK」店だけで 500 を超えられる）。

### Phase 1 店舗ページ化（286 → 約590）
1. 記事ID ↔ 詰めOKリストの Maps URL を対応付け（automation/stores500/map.json、個人情報は保存しない）
2. Googleマップの店舗パネルから基本情報を取得（scripts/fetch-gbp-details.mjs、Playwright、無料、6〜10秒間隔）
3. 記事＋GBP から Restaurant を組み立て（新ファイルに分離して自動生成パイプラインと衝突させない）。
   取れない項目は推測で埋めず「—（訪問前に公式確認）」
4. 地域を都道府県単位で拡張（三重・沖縄・山口・石川…）
5. 店舗ページ ⇔ 特集記事を相互リンク。Supabase 同期（漏れている58店も）・座標・sitemap
6. 品質ゲート（実写画像・住所/営業時間あり・本文量）を満たす店だけ index

### Phase 2 街 → 店
- 市区町村ごとの「街」ページ（掲載店の地図と一覧）。3店以上の街には事実ベースの街紹介（WebSearch 検証・マチノワ編集部トーン）
- 地域ハブ → 街 → 店 の導線

### Phase 3 利用シーン
- 全店にシーンタグを事実から付与（席の表記→個室・座敷・カウンター、営業時間→ランチ・深夜、席数→宴会、記事の推奨シーン）
- シーン×地域ページ、シーン別の特集記事（タグの根拠となる事実を店ごとに明記）

### Phase 4 自動化
- 詰めOK の新店は、記事と同時に店舗ページ・タグも自動生成（local-pipeline.sh の後段に追加）

## 守ること
- 実在店のみ・事実のみ・星評価や口コミの転載なし・誇張表現なし
- 有料API禁止（Google Places 等）。スプシは読み取りのみ（書き込みは既存パイプラインの書き戻しだけ）
- 作業は worktree `/Users/shunta/claude/gp-content`（ブランチ content/stores-500）。main への統合は記事自動生成が止まっている時間帯（08:00/22:00 の実行中は避ける）
- 実行はサブエージェント（haiku 基本）。完了判定は成果物（本番URL・データ件数）で行う
