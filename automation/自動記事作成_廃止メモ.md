## 5. 作り直すときに引き継ぐべき教訓

まず **`automation/申し送り.md`** と **`automation/記事URL運用ルール.md`** を読む。要点は次のとおり。

1. **スプシの行ズレ**: 「詰めOKリスト」は IMPORTRANGE+QUERY のビューで、行が 1 件増えるだけで全行がずれる。W/X など手動の列を行番号で書くと別の店に「済」「URL」が付く。書き込みは必ず「本体」シートの行、または顧客管理 ID・cid・店名などの固有キーで。列を動かしたら残骸(V 列以降の値)を消す。
2. **台帳の偽エントリ**: 記事が無いのに「生成済み」になった台帳エントリ(例: `SEAFOODBOWL SHOP IN TANASHI` が記事 ID `OWL` で登録)で、その店が永久に候補から消える。台帳の記事 ID は実在を確かめる。
3. **「候補 0 件」「成功 N 件」は完了の証拠にならない**: クールダウン・ロック・偽エントリで隠れる。完了は **成果物の実在(詰めOK行 × 記事の全数照合)** で判断する。実際に 3 回取りこぼした。
4. **重複生成**: 店名と記事 ID の照合は **完全一致(NFC 正規化後)のみ**。中間一致(`includes`)は禁止(`OWL ⊂ SEAFOODBOWL` で店が消えた)。記事 ID が既にあれば生成に入らない。
5. **NFC / NFD**: Google マップ由来の店名は NFD(`e` + 結合文字)で届くことがあり、記事 ID・台帳・URL・反映確認の文字列が食い違って「毎回偽エントリ → 7 分空回り → 反映失敗」になった(French Restaurant rêve、2026-10-09〜13)。ID を作る所と比べる所で必ず NFC に揃える。
6. **記事 ID の記号**: スペース・`/`・`?`・`&`・`#`・`%` などを落とす。`tr -d` は UTF-8 を壊すのでシェルのパラメータ展開で 1 文字ずつ落とす。スラッシュが残ると `/feature/A/B` になり 500 になる。
7. **日本語 URL**: スプシ・報告に書く記事 URL は **日本語表記のまま**(パーセントエンコードしない)。D 列などは HYPERLINK 式でなく、セルに直接リンクを埋める。Next.js 側の日本語 URL 500 は 16.3.5 で解消済み。
8. **環境起因の失敗を店のエラーにしない**: 認証切れ・ネット断をスプシの W 列に「エラー」と書くと 24 時間クールダウンに入り滞留が見えなくなる。実行前に環境を確かめ、壊れていたら何も書かずに撤退。
9. **無人実行の落とし穴**: 「待つ」「聞く」で止まるのが失敗の約 6 割。サブエージェント委譲・完了通知待ち・質問は禁止し、必ず「COMPLETED …」か失敗の出口で終わらせる。ログの自己申告は信じず、記事の実在で判定する。
10. **文章の禁止事項**(記事の中身): 料金・価格を書かない/禁止語(素朴・派手さはない・日本一・絶品・最高の・呼び込み など)/他サイトの点数・星・評価・口コミ件数/「公式サイトによると」など出どころの引用の言い回し/評価の断定(地元で人気・評判の店・知る人ぞ知る)/行ったふり(〜と感じた)/分からなかったことを書く文・調べ方の舞台裏・決まり文句の締め。`spec.md §14-0` の「文章の 6 つの型(R/A/B/C/D/E)」は `scripts/check-article-sentences.mjs` と `lib/thinSentences.ts` で機械的に検査・除去できる。脱テンプレ規約(closing を「編集部が考える」で始めない等)も spec §14。
11. **店の取り違え**: 店名だけで検索すると同名別店舗を拾う。Maps URL が絶対の正解(座標からの逆引きは禁止)。住所の都道府県・市区町村が一致しない情報は採らない。店の写真・情報は別々の手がかり 2 つ以上で同じ店と確かめる。画像は実店舗のものだけ(汎用画像・AI 生成画像は店舗紹介に使わない)。
12. **デプロイは push だけでは反映されないことがある**: 本番 URL を実際に叩いて 200 を確かめる(転送 308 はたどる)。本番は `public/restaurants` を含む完全な作業場所から出す。
13. **スプシへの書き込みは事前承認**。有料 API を無断で回さない。Gmail に下書き・メールを作らない。

## 6. 戻し方

- 全部戻す: このコミットを `git revert <このコミット>`
- 1 ファイルだけ戻す(削除前の最後の状態は main の `16e9a9cd`):
  `git checkout 16e9a9cd -- automation/local-pipeline.sh`(他のファイルも同様)
- launchd の予約は、plist の写し(上記 5 本)を `~/Library/LaunchAgents/` に置いて `launchctl bootstrap gui/$(id -u) <plist>` で登録する(入れ方は `INSTALL-LOCAL.md`)。ただし **再開する前にオーナーの許可を取ること**。
