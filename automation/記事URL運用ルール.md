# 記事URLとスプレッドシートの運用ルール（必読・2026-08-26 制定）

このファイルは「同じ調査を二度としない」ために作った。
スプシ絡みで作業する前に**必ずここを読む**。憶測で触らない。

---

## 1. どこに何があるか（列構成の正）

単一情報源は `scripts/sheets-config.mjs`。**構成が変わったらそこだけ直す。**
以下は 2026-08-26 時点の実測値。

### トスアップ元シート（本体）
- A1 が `=IMPORTRANGE(... Linkate②!A1:V10000)` → **A〜Rは取り込み。人もbotも書いてはいけない**
- `A=顧客管理ID` `D=店舗名` `K=Maps URL(cid入り)` `Q=詰めステータス`
- `W=特集記事_済` `X=特集記事_URL` … パイプラインが書く（IMPORTRANGE展開域の外なので書ける）

### 詰めOKリスト（ビュー）
- A1 が `=QUERY('トスアップ元シート'!A:R,"SELECT * WHERE Col17='詰めOK'",1)`
- `S=済` `T=表示用URL(日本語)` `U=コピー用URL(ASCII)` … **全て数式。手で値を入れない**

### 記事台帳（唯一の正データ）
- `A=顧客管理ID` `B=店舗名` `C=記事ID`
- `automation/sync-article-ledger.mjs --apply` で再構築（冪等）
- `scripts/sheets-mark-done.mjs` が記事完成時に顧客管理IDでupsert

---

## 2. 絶対に守ること

1. **QUERY出力の右隣に「値」を置かない。** 詰めOKが1件増えるたびに必ず行ズレする。
   2026-08-17 に W/X で21行、2026-08-18 に S/T で28行の実害が出た。
   S/T/U は必ず「自分の行の $A列（顧客管理ID）で記事台帳を引く数式」にする。
2. **日本語URLは平文だとリンクにならない。** 自シートでも貼付先でも同じ。
   - 自シート内で押せるようにする → `HYPERLINK()`
   - 他シートへ渡す → `ENCODEURL()` でASCII化した U列を、値のみ貼り付け(⌘⇧V)
3. **店舗名の中間一致(includes)は禁止。** OWL ⊂ SEAFOODBOWL で店舗が消えた事故がある。
   照合は cid（Maps URLの`cid=`数値）が第一。次に正規化後の完全一致。
4. **画像が無い店は記事を作らない。** 迂回して公開した結果が「真っ黒画像30件」。
   20KB閾値はGoogleのフォールバック画像(20,558 bytes)が78バイト差ですり抜けるので当てにならない。
5. **本番スプシへの書き込み前に必ずバックアップを取る**（`automation/backup-*.json`）。

## 4. 「記事が抜けている」と言われたときの手順

集計値（`未処理 0件`）は**嘘をつく**。24hクールダウン中の失敗や、
済フラグの誤りで抜けが隠れる。実際に3回それで取りこぼした。

```bash
# 1. 記事の実在ベースで抜けを出す（これが唯一信用できる）
node scripts/check-gaps.mjs

# 2. 抜けが「エラー: ...」でクールダウン中なら、ロックを外す
node scripts/sheets-mark-done.mjs --type=feature --row=<行> --status=clear --force

# 3. 生成
./automation/local-pipeline.sh manual

# 4. 台帳とS/T/Uを同期
node automation/sync-article-ledger.mjs --apply

# 5. 再確認
node scripts/check-gaps.mjs
```

## 5. 既知の失敗モードと原因

| 症状 | 原因 | 対処 |
|---|---|---|
| 店舗名とURLがずれる | QUERYの右に手動値を置いた | S/T/Uを数式化（対策済み） |
| URLが黒文字でクリックできない | 日本語URLは自動リンク化されない | HYPERLINK / ENCODEURL |
| 貼付先でリンクにならない | 日本語URLを値貼りした | U列(ASCII)を使う |
| URL末尾に `**` が付く | claudeの出力文から正規表現でURLを拾っていた | SAFE_NAMEを正とする(修正済 f7ea406) |
| `未処理0件`なのに抜けがある | 24hクールダウンで失敗が隠れる | `check-gaps.mjs` |
| 夕方の案件が翌朝まで作られない | 夜間便がクラウドで空振り(実行セッション0件) | ローカル20時便を復活させる |
| claude早期終了 | 600秒のバックグラウンド待ちで強制終了 | status=clear で再投入 |
