## 組み方
- PC(>768px): 各帯が固定の高さ(`calc(var(--u) * N)`)で、中の部品は `P(l,t,w,h)` の座標(見本の画素)で絶対配置。`--t` は属する帯の上端(見本の y)からの値。
  帯の上端(見本の y): ヒーロー 55 / 営業情報 426 / ギャラリー 556 / おすすめ 761 / 店内 1020 / 関連 1303(main 内の y = 見本の y − 55)。
  文字は字の見た目の上端(ink top)を `--t` に書き、CSS の `--o`(字の上の余白)を引いて置く。`--dx` は字の左の余白(左端を見本に揃える)。
- ≤768px: 縦に積む。ヒーローは「画像 → 暗い地に文字」、営業情報は 2 列、ギャラリー/おすすめ/店内の小写真は 2 列、暖簾は `--bu: 1.1px`(見本の 1.1 倍)で上に置く。本文 14px 以上・押す所 44px 以上。
- 暖簾(布)は切り出し画像(文字なし・alpha つき)+ HTML の文字。判子(赤い四角)は布の絵の一部として画像に残してある。
- ギャラリーは `Gallery.tsx`(client)。矢印で写真を 1 つずつ送る(各スロットの幅は見本どおり不揃い・`object-fit: cover`)。写真を押すと全画面(暖簾 2 の方式を写した・Esc / ←→ / 背景クリック)。
