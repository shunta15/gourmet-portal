# マチノワ 4 業種(グルメ・アクティビティ・スポーツ・くらし)の動きの設計(2026-11-05)

オーナーの指示: 「ページにスクロールアクションや web アクションがないから追加して。デザインは全く変えるな。すでにあるデザインに動きをつけて」。
決まり: 配置・色・文字・画像・札の枚数は一切変えない。新しい帯・文字・飾りを足さない。飾りを顔や文字に重ねない。指摘された部品だけ直す。

## 0. 共通の仕組み(`components/portal/motion/`)

- `PageMotion`(client・何も描画しない)を各業種の外枠に 1 つ置く。要素に `data-mo-*` 属性を付けるだけで動く(class・DOM・CSS の値は変えない)。属性の一覧は README.md。
- **きっかけと時間(全業種共通)**

| 種類 | きっかけ | 時間 |
| --- | --- | --- |
| 出現(ポップイン・スライド・フェード・マスクリビール・ブラーイン・ラインドロー) | 要素の 8% が画面に入ったとき(下端 8% の手前)。1 回だけ | up/left/right/fade 0.8〜0.9 秒・pop 0.7 秒(オーバーシュート)・wipe 0.9 秒・blur 0.9 秒・draw 1.3 秒。イージングは全部「緩急」 |
| スタガー | 同じ組(`data-mo-group`)の中で順番にずらす | 札は 80ms ずつ(最大 12 枚目まで)、文字の部品は 110ms ずつ |
| 視差(パララックス) | スクロール(rAF 1 本) | 画面中心とのずれ × 0.04〜0.08。飾りだけ。文字・顔写真に重なる飾りには使わない |
| 触る反応 | hover(マウス)/ :active(タップ) | lift 3px 浮く 0.35 秒・zoom 写真が 4.5% 寄る 0.6 秒・tilt 傾く 0.25 秒(マウスだけ)・press 押すと 3% 縮む 0.18 秒 |
| ずっと動く | 開いた瞬間から。画面の外・非表示タブでは止まる | kb(写真がゆっくり寄る)18 秒往復・float(ふわふわ)5.5 秒・sway(ゆらゆら ±0.8°)7 秒 |
| 動きを減らす設定 | OS の prefers-reduced-motion | 何も動かさず全部表示済み |

- 1 ページの最初の画面(ファーストビュー)は、開いた瞬間に上からスタガーで出る(IO が即時に発火する)。ただし **最大の写真(LCP)は隠さない**(kb か無し)。
- 既に動きがある所(グルメの `data-rv`・読み込み時の animation・hover 拡大)は重複して付けない。
- 属性を付ける位置の決まり: `transition`/`transform`/`clip-path`/`filter` を自分で持つ要素には、それを取り合う種類を付けない(README の表)。付けられないときは親(li)か子(a)に付ける。

## 5. 確認の仕方

- ローカル `PORTAL_LAUNCHED=1 npm run dev`(分岐 gp-k-motion・ポート 6250)で 4 業種×4 種類のページを 375 / 768 / 1280 幅で見る。本番は見ない。
- 見るもの: (1) 開いた瞬間に最初の画面がスタガーで出るか、(2) スクロールで順に出るか、(3) hover/タップで反応するか、(4) **配置・色・文字・札の枚数が前と同じか**(前後のスクショを並べる)、(5) 飾りが文字・顔写真に重なっていないか、(6) reduced-motion で全部見えるか、(7) `npm run build` が通るか。
