## 布札 7 のテーマと理由
実在の記事が 1 本以上ある分け方だけを選んだ(`Feature.tag` の完全一致。件数は 2026-11-02 時点でデータから数えた値)。

- 試作の「ひとり時間」「家族で」は、見本の言葉のままでは「ひとり」の記事が無いので、実在する分け方に置き換えた。暖簾の絵柄の枠(位置・布)は試作のまま、傘の絵だけ `icons.tsx` に自作。
- 各布札の title = そのテーマで日付がいちばん新しい記事の title の最初の文(長ければ読点で切る。`fit()`)、desc = 同じ記事の lede の最初の文(文の頭から。`leadSentence()`。64 字を超えるときだけ読点で止める。字は変えない)。写真 = その記事の heroImage。エリア別だけ「N 地域の特集を、エリアから探す」(N はデータから数える)・記事の多い地域名 5 つ。
- 布札(暖簾・カード)を押す → 同じページ内のそのテーマの節 `#gn-fl-sec-<枠>`。節 = 見出し帯(「◯◯の特集」+本数)+そのテーマの新しい記事の札(最大 8)+「すべて見る」(`/feature?theme=…`)。エリア別の節は地域ごとの新しい 1 本(記事の多い 8 地域)+ 19 地域のリンク(`?region=`)。
- 新着 5 = 日付の新しい 5 本(同じ日付は FEATURES の並び順)。注目 = 新着の 1 本目。右の紙のインスタント写真 = 新着の 2 本目の写真。

## URL の絞り込み
`?region= ?theme= ?tag= ?q= ?all=1` の意味は今までの page.tsx と同じ(重ねて絞る)。違いは 1 点だけ: `?theme=` が布札のテーマの名前のときは、その表の tag 集合(表記ゆれを足した分)で絞る(それ以外の名前は今までの `filterByTheme`)。
絞り込みがあるときは、見本の上部(ヒーロー・布札・注目・テーマのカード・キーワード欄)はそのまま出し、新着・各テーマの節は出さず、その下に結果の節だけを出す。generateMetadata(q/tag は noindex)・canonical は変えない。

## 見本に無い追加
- キーワード欄(旧 /feature/search → ?q= の入口。GET フォームだけ)。
- エリア別の節の 19 地域リンク(旧 /feature/region/<キー> → ?region= を受けるため)。
- 各節の見出し帯の本数、結果の節の「絞り込みを外す」。

## 文言(見本の仮の言葉を使わない)
見出し「特集を、読む。」・リード(シーン別まとめ記事は…)は旧 /feature の文。注目の札「新着の特集」・右の紙「PICK UP FEATURE」「いちばん新しい特集記事をご紹介。+日付」・下帯「特集 N 本を、一覧で読む。」「シーン別まとめ記事 N 本・街歩き・コース N 本。」は事実(数・日付はデータ)だけ。
