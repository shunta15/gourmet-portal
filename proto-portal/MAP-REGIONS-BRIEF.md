# 「地図で探す」を、地方から選ぶデフォルメ地図に変える（試作）

オーナーの指示（2026-10-05）: 「地図がリアルすぎるから変更してほしい」「〇〇地方とかで選べるようにしてほしい」。
下の案を出し、「進めて」と承認された。

## 対象

`/map` だけ（`components/portal/pages/map.tsx`・`MapExplorer.tsx`・`PortalMap.tsx`・`lib/portal/mapData.ts`）。
公開スイッチが ON のときだけ動く。OFF のグルメは 1 バイトも変えない（`compare-off.mjs` で確認）。

## 作るもの

1. **最初の画面 = デフォルメした日本地図**
   - 自作の SVG。47 都道府県をブロック（四角など）で並べ、8 地方で色分けする。実測の海岸線データは使わない。
   - 8 地方: 北海道／東北／関東／中部／近畿／中国／四国／九州・沖縄。サイト内に地方の区分が既にあればそれに合わせ、食い違いは報告する。
   - 地方ごとに店数を出す。
   - 地図を使わない人のために、同じ内容のリスト（地方 → 県）も置く。キーボードで操作でき、読み上げで「関東地方 ◯店」と分かること。
2. **地方を選ぶ → その地方の県が店数つきで並ぶ**
   - 0 店の県は押せない表示にする（リンクにしない）。
   - 業種の絞り込み（既存のチップ）と、営業中の件数表示は残す。
3. **県を選ぶ → 店の一覧とピンの地図**
   - ピンの地図は、道路や地形の無い背景にする。第一候補は国土地理院の「白地図」。
   - 使えるズームの範囲・出典の書き方・利用条件を、地理院の公式ページで確かめてから使う。
   - 使えない、またはズームが足りないときは、代案を決めて報告する。
4. **URL に状態を残す**（例: `/map?r=kanto`、`/map?p=tokyo`）
   - いまある駅・エリアのフォーカス用の指定は壊さない。ブラウザの「戻る」で前の段に戻る。
5. **店数は実データから数える**
   - `mapData` の値だけを使う。数を作らない。
   - 位置の取れていない店は地図に出さず、その旨の注記を残す。
   - 「地方の合計 = 県の合計 = 全体」を検査で確かめる。

## 変えないもの

店・駅・地域・街・シーンの各ページの地図。`PortalMap` は共有なので、背景の切り替えは `/map` だけに効く形（prop など）にする。

## 見た目と使い勝手

- 既存のポータルの色・書体（`portal.css` のトークン）に合わせる。
- PC 1440 とモバイル 390 の両方で、横スクロール 0。押せる要素は 44px 以上。コントラストは AA。
- `prefers-reduced-motion` を尊重する。

## してはいけないこと

- 架空の店や数、星評価、誇張。
- 実行時の `fs`（`public/` を読む処理）。
- 外部の地図画像やライブラリの追加（必要なら、理由・ライセンス・サイズを報告してから）。
- push、vercel、main の作業ツリーへの変更、`pkill`（サーバーはポート指定で止める）、エージェントの入れ子。
- `.env.local` などの中身を表示すること。

## 検査

- `npx tsc --noEmit`、`test-facets`、`test-openNow`。
- `crawl.mjs` で PROBLEMS 0。`check-keyboard`・`check-contrast`・`check-jsonld`・`check-foundation`。
- `compare-off.mjs` の static と live（main と比べて PROBLEMS 0）。
- Playwright（PC・モバイル）: 地方 → 県 → 店の流れ、戻る、URL の直打ち、業種チップ、0 店の県。スクショは 8 枚まで。
- `next dev` が `AGENTS.md` を書き換えたら `git checkout AGENTS.md` で戻す。
