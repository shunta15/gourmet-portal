# ビューティー 作り直し 案4「ラグジュアリー LUXE」 — ルート /proto-hub/beauty-luxe  ポート 3354
銀座や高級ホテルの中の、落ち着いた大人のサロン。
- 色: 深いトープ(灰茶)#2e2925 と、あたたかい大理石の白 #f2ede6 の 2 面。差し色はシャンパンゴールド #c9ad7f(細い線・小さな文字だけ。べた塗りにしない)。文字は、暗い面では象牙 #efe7da、明るい面ではトープ。
- 書体: 欧文 Cormorant Garamond(300・500。大文字・字間広め)と Italiana。和文 Shippori Mincho(400・500)。
- 最初の画面: 左の 6 割が深いトープの面、右の 4 割が大理石の面(ごく薄い石目を CSS か Canvas で。派手にしない)。境目に、金の細い縁の、大きな丸い鏡。鏡の中は、あたたかい間接照明のようなやわらかい光がゆっくり動く。左に大きな欧文 `BEAUTY`(細い)と和文のブランド名。金の細い線。
- 下: 「種類から探す」は、大理石の面の上の、金の細い線で区切ったメニュー表(コースの品書きのように)。都道府県は、トープの面に象牙の字。
- 動き: 鏡の中の光がゆっくり呼吸する。文字と線が、ゆっくり、順に現れる。カーソルで鏡の光がわずかに動く。
- 注意: 黒と金のぎらぎらした画面にしない。暗い面は茶みのある灰。全体は静かで、やわらかい。
